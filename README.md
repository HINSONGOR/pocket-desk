# Pocket Desk

A single-page personal hub. Everything is in one file, `index.html`, and it has no build step.

- **Inbox 收集箱**: capture anything first. You can then move each item to To-do, Notes or the Prompt library in one click.
- **AI 指令庫**: prompts sorted by category, with search, favourites and one-click copy.
- **待辦**: your own lists with colours, plus priority, due dates, and filters for today, overdue and upcoming.
- **筆記**: notes that autosave, with pinning and tags.
- **主題**: the original clean theme plus 7 cartoon themes: candy, ocean, forest, orange, grape, lemon and night.

## Data

When you open the page as a standalone site (for example GitHub Pages), your data stays in that browser's `localStorage`. Nothing is uploaded. Clearing the site's data or switching browsers starts you from empty.

The Claude artifact version of the page syncs its data to the cloud.

## Run

Open `index.html` in a browser, or visit the GitHub Pages site.
